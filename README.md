# GH-300 GitHub Copilot Study Guide

A community-maintained study guide for **Exam GH-300: GitHub Copilot**. Use this repository to understand the exam, organize your preparation, and share useful learning resources with other candidates.

> [!NOTE]
> Exam objectives can change. This guide reflects the official outline available on **August 28, 2026**. Always compare it with the [official GH-300 study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/gh-300) before scheduling your exam.

## Certification overview

GH-300 validates your ability to use GitHub Copilot to improve software development productivity, quality, and security. It covers responsible AI, Copilot features and plans, prompt engineering, data handling, privacy, and safeguards.

## Requirements

Microsoft does not publish a formal prerequisite certification for GH-300. Candidates are expected to have:

- Practical experience using GitHub Copilot to improve productivity, code quality, and security.
- Familiarity with GitHub fundamentals.
- Experience with at least one programming language.
- Knowledge of responsible AI, prompt engineering, GitHub Copilot plans and features, privacy, and content safeguards.
- A personal Microsoft account connected to a [Microsoft Learn profile](https://learn.microsoft.com/users/). Microsoft recommends using a personal account so certification records are retained if you leave an employer or school.
- A suitable computer, identification, and testing environment that meet the [online proctored exam requirements](https://learn.microsoft.com/credentials/support/online-exams).

Review the [exam policies and FAQs](https://learn.microsoft.com/credentials/support/certification-exam-policies) and request [exam accommodations](https://learn.microsoft.com/credentials/certifications/request-accommodations) before scheduling when applicable.

## Skills measured

The official outline dated August 7, 2026 lists these areas:

- **Use GitHub Copilot responsibly (15-20%)**
  - Understand responsible AI principles, risks, limitations, harms, and mitigations.
  - Validate AI output and operate AI tools responsibly.
- **Use GitHub Copilot features (25-30%)**
  - Work with inline suggestions, chat, Copilot CLI, agent mode, Copilot Edits, MCP, agent sessions, and sub-agents.
  - Use code review, Spaces, Spark, pull request summaries, prompt files, and custom instructions.
  - Manage organization policies, audit events, and subscriptions.
- **Understand GitHub Copilot data and architecture (10-15%)**
  - Explain data flow, prompt construction, proxy filtering, post-processing, and the suggestion lifecycle.
  - Recognize the limitations of large language models and Copilot.
- **Apply prompt engineering and context crafting (10-15%)**
  - Structure effective prompts and supply relevant context.
  - Use zero-shot and few-shot techniques, chat history, and prompt engineering practices.
- **Improve developer productivity with GitHub Copilot (10-15%)**
  - Generate, refactor, document, test, and modernize code.
  - Identify edge cases and improve security and performance.
- **Configure privacy, content exclusions, and safeguards (10-15%)**
  - Configure privacy, editor settings, content exclusions, and public-code matching filters.
  - Understand output ownership and troubleshoot excluded or missing suggestions.

> [!IMPORTANT]
> The current official outline repeats "GitHub Copilot features (25-30%)" as a separate line without supporting objectives. The list above consolidates that apparent duplicate. Treat the [official study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/gh-300) as authoritative if Microsoft updates it.

## Suggested study plan

### 1. Learn the foundations

- Complete [GitHub Copilot Fundamentals, Part 1](https://learn.microsoft.com/training/paths/copilot/).
- Complete [GitHub Copilot Fundamentals, Part 2](https://learn.microsoft.com/training/paths/gh-copilot-2/).
- Review [GitHub Copilot plans and features](https://docs.github.com/copilot/about-github-copilot/plans-for-github-copilot).

### 2. Practice responsible use and prompting

- Study [responsible AI with GitHub Copilot](https://learn.microsoft.com/training/modules/responsible-ai-with-github-copilot/).
- Practice the guidance in [prompt engineering for GitHub Copilot Chat](https://docs.github.com/copilot/using-github-copilot/copilot-chat/prompt-engineering-for-copilot-chat).
- Verify generated code for correctness, security, licensing concerns, performance, and maintainability.

### 3. Build hands-on experience

Use Copilot in a small project to:

- Generate and explain code with inline suggestions and chat.
- Refactor existing code and create documentation.
- Generate unit and integration tests, including edge cases.
- Review a change for security and performance issues.
- Create repository instructions and reusable prompt files.
- Explore agent mode, Copilot CLI, MCP, code review, and content exclusions where your plan supports them.

### 4. Review privacy and architecture

- Read [how GitHub Copilot handles data](https://github.com/trust-center).
- Configure and test [content exclusions](https://docs.github.com/copilot/managing-copilot/configuring-and-auditing-content-exclusion).
- Be able to explain how context becomes a prompt and how a suggestion is filtered and returned.

### 5. Check exam readiness

- Take the free [practice assessment](https://learn.microsoft.com/credentials/certifications/github-copilot/practice/assessment?assessment-type=practice&assessmentId=218035372&practice-assessment-type=certification).
- Try the [exam sandbox](https://aka.ms/examdemo) to learn the testing interface.
- Revisit weak skill areas and repeat hands-on exercises without relying on memorization alone.
- [Schedule the GH-300 exam](https://learn.microsoft.com/credentials/certifications/schedule-through-pearson-vue?examUid=exam.GH-300&examUrl=https://learn.microsoft.com/credentials/certification) when you are ready.
